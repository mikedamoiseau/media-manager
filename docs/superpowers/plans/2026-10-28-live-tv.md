# Live TV Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner picks French and Belgian channels from iptv-org in Settings; the app writes the one channel list both Kodi TVs read from the NAS, keeps a TV guide from XMLTV sources, shows it on a Live TV page (grid on wide screens, list on narrow ones), and starts a channel on the chosen TV or in VLC on the phone.

**Architecture:** Pure modules first: `server/epg.ts` (XMLTV read as a stream, guide matching) and `server/iptv.ts` (iptv-org lists in, the NAS file and VLC's one-channel playlist out). `server/livetv.ts` keeps the catalog, the owner's picks and the guide in SQLite and runs the daily refresh, the stream checks and the NAS write. `server/liveKodi.ts` finds and starts a channel on a TV. `server/liveApi.ts` adds the `/api/livetv/*` routes. The web app gets pure helpers (`web/src/liveTv.ts`), the Live TV page and a Settings panel.

**Tech Stack:** Node ≥ 24 (TypeScript strip-only: no enums, no parameter properties), Hono, node:sqlite, node:zlib, React 19 + Vite + wouter, node:test.

**Spec:** docs/superpowers/specs/2026-10-28-live-tv-design.md

## Global Constraints

- Channel lists: `https://iptv-org.github.io/iptv/countries/fr.m3u` (list `fr`), then `https://iptv-org.github.io/iptv/countries/be.m3u` (list `be`). A channel's key is its `tvg-id` with its feed (`TF1.fr@SD`); when both lists have it, the first list wins.
- NAS file: setting `liveFile`, default `/Volumes/video/IPTV/channels.m3u`; an empty `.nomedia` next to it. The app creates only that folder, never the share root, never anything inside `MEDIA`.
- File entries: iptv-org's `tvg-id`, `tvg-logo`, `group-title`, every `#EXTVLCOPT`/`#KODIPROP` line as is, `tvg-chno` = position 1..n in the owner's order, `tvg-name` = the written name (unique).
- Guide sources, in priority order (setting `liveGuides`): `https://xmltvfr.fr/xmltv/xmltv.xml.gz`, `https://i.mjh.nz/PlutoTV/fr.xml.gz`.
- Guide matching, first hit wins: manual pick; `tvg-id` without `@…` equal to a guide id ignoring case; aliases `TFX.fr`→`NT1.fr`, `LCP.fr`→`LaChaineParlementaire.fr`, `RMCStory.fr`→`Numero23.fr`, `LEquipe.fr`→`LEquipe21.fr`; Pluto id from the stream address (`plu-<24 hex>`) equal to a guide id; else no guide. Sources tried in priority order.
- Refresh: lists and guides once a day, inside the app (on start when the last one is over 24 h old, and checked hourly). No new service, scheduled job or container anywhere. No new npm dependency.
- Play on a TV: find the channel by its written name (number only breaks ties); never reuse one TV's channel id on another; check about 10 s later that something plays.
- No live TV in kids mode: no Live TV tab, every `/api/livetv/*` route refused for a kids profile, and no channel started on a TV whose `Skin.HasSetting(CinemathequeKids)` is true or can't be read.
- Live TV plays are not library plays: no `owners.touch`, `notePlay` or `recordActivity`.
- Phone: VLC gets the stream address itself; a channel with `#EXTVLCOPT`/`#KODIPROP` lines gets `/api/livetv/<key>/vlc.m3u` (three lines plus its option lines). No video through the Mac, never the whole list.
- Grid when the screen is at least 700 px wide, else list; the Grid/List switch wins until the screen's width or height changes. The grid opens at now − 30 min. Times in the device's local time.
- The repository is public: no personal data in code, tests or commits (the NAS address only in the default `liveFile` path, like `mediaRoot`).
- Tests use `node:test` (`npm test`); `npm run typecheck` and `npm run build` pass after every task. Every task gets a Codex review before its commit is final; push only when the owner asks.

## Review Focus

1. An `#EXTINF` line whose attribute holds a comma (`http-user-agent="Mozilla/5.0 (KHTML, like Gecko)"`): the name is what follows the first comma outside quotes — pinned in Task 2.
2. The NAS not mounted when the file is written: nothing is created under `/Volumes` (a local folder there would shadow the share later); the picks are still saved and Settings says the NAS isn't mounted — pinned in Task 4.
3. One guide source down or returning HTML: its previous programmes stay; the other source still refreshes — pinned in Task 4.
4. A TV that hasn't reread the list (channel ticked since), that doesn't answer, or whose kids view can't be read: a clear refusal, never another channel — pinned in Task 5.
5. iptv-org drops a channel the owner ticked: the pick stays, its last known entry is still written, Settings shows it as no longer listed — pinned in Task 3.

test('XMLTV times keep their offset (summer +0200, winter +0100)', () => {
  assert.equal(xmltvTime('20261028120000 +0100'), Date.UTC(2026, 9, 28, 11, 0, 0));
  assert.equal(xmltvTime('20261025013000 +0200'), Date.UTC(2026, 9, 24, 23, 30, 0));
  assert.equal(xmltvTime('20261028120000'), Date.UTC(2026, 9, 28, 12, 0, 0), 'no offset: UTC');

test('channels then programmes, whatever the chunk boundaries', async () => {
  for (const size of [7, 64, XML.length]) {
    const chunks = async function* () { for (let i = 0; i < XML.length; i += size) yield XML.slice(i, i + size); };
    const ch: GuideChannel[] = [];
    const pr: Programme[] = [];
    await readXmltv(chunks(), { channel: (c) => ch.push(c), programme: (p) => pr.push(p) });
    assert.deepEqual(ch, [{ id: 'TF1.fr', name: 'TF1' }, { id: 'NT1.fr', name: 'TFX' }]);
    assert.deepEqual(pr, [

      { channel: 'NT1.fr', start: Date.UTC(2026, 9, 24, 23, 30), stop: Date.UTC(2026, 9, 25, 0, 0), title: 'Nuit' },
    ]);
  }
});

test('a guide channel for a playlist channel: id, then aliases, then Pluto, sources in order', () => {
  const ids = (...a: string[]) => new Map(a.map((x) => [x.toLowerCase(), x]));
  const guides: GuideIds[] = [
    { source: 'https://xmltvfr.fr/xmltv/xmltv.xml.gz', ids: ids('TF1.fr', 'NT1.fr', 'MaTele.be') },
    { source: 'https://i.mjh.nz/PlutoTV/fr.xml.gz', ids: ids('TF1.fr', '6823648580b2665220d9e69a') },

  assert.deepEqual(matchGuide({ key: 'Matele.be@SD', url: 'http://a' }, guides), { source: x, id: 'MaTele.be' }, 'case ignored');
  assert.deepEqual(matchGuide({ key: 'TFX.fr@SD', url: 'http://a' }, guides), { source: x, id: 'NT1.fr' }, 'alias');

- [ ] **Step 3: Implement `server/epg.ts`**

`readXmltv` keeps a text buffer, cuts whole `<channel …>…</channel>` and `<programme …>…</programme>` elements out of it as they complete (each is small), reads attributes and the first `title`, `sub-title`, `desc`, `category`, `display-name` text and `icon src` with regular expressions, decodes `&amp; &lt; &gt; &quot; &apos; &#NN; &#xNN;`, and drops what it has read so the buffer never holds the whole file. Missing optional fields are left out of the object (not `undefined` keys). A programme without `start`, `stop`, `channel` or title is skipped. `GUIDE_ALIASES = { 'tfx.fr': 'NT1.fr', 'lcp.fr': 'LaChaineParlementaire.fr', 'rmcstory.fr': 'Numero23.fr', 'lequipe.fr': 'LEquipe21.fr' }`. `matchGuide`: for each source in order, try the id without feed, then the alias, then `/plu-([0-9a-f]{24})/` from the url.
